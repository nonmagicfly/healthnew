## Why
Пользователь записывает разговор с врачом и хочет хранить его рядом с заключением. Расшифровка должна идти на его компьютере: запись не уходит во внешние сервисы.

## What Changes
- Загрузка записей разговора (.m4a, .mp3, .wav, .ogg, .opus, .webm, .aac) до 300 МБ. Оригинал хранится без изменений, на странице документа есть плеер.
- Расшифровка в фоне локальной моделью Whisper (transformers.js + onnxruntime, ffmpeg для декодирования). Модель скачивается один раз в каталог данных.
- Реплики с таймкодами, говорящий помечен «неясен»: модель не различает врача и пациента. Дата записи берётся из тегов файла, если пользователь её не указал.
- После расшифровки документ обрабатывается как текстовая расшифровка. Модели с согласием уходит только текст, не запись.
- Прерванная перезапуском расшифровка продолжается при старте; после ошибки её можно запустить снова.
- Образ Docker на Debian (onnxruntime нужен glibc) с ffmpeg.
