## ADDED Requirements

### Requirement: Врачи
Система SHALL показывать консультации и записи разговоров по специальностям. Каждый приём SHALL сопровождаться жалобами, диагнозами, назначениями, обследованиями и датой повторной явки из сохранённых фактов этого документа, а каждая специальность — последним заключением, ближайшей явкой и клиниками. Выжимка MUST NOT создаваться моделью и MUST NOT включать отклонённые факты. Упоминание о приёме препарата MUST NOT показываться как назначение.

#### Scenario: Запись разговора
- **WHEN** у записи разговора не указан врач, а в тот же день есть консультация кардиолога
- **THEN** запись показывается в папке «Кардиолог» рядом с этой консультацией

### Requirement: Вопрос по выбранным документам
Пользователь SHALL иметь возможность отметить несколько документов и задать по ним вопрос. Без отдельного согласия ответ MUST собираться локально только по фактам выбранных документов. Текст документов MUST уходить в модель только после согласия в этом окне и только внутри блока недоверенных данных. Вопрос и ответ SHALL сохраняться в чате.

#### Scenario: Вопрос без модели
- **WHEN** пользователь отмечает консультацию, спрашивает «Какие препараты назначены?» и не даёт согласия на отправку
- **THEN** ответ собран по шаблону из фактов этой консультации, ничего не отправлено
