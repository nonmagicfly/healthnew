## ADDED Requirements

### Requirement: Автоматическая разметка документа
Система SHALL заполнять пустые тип, раздел, врача и клинику документа из результатов разбора: бланк лаборатории получает тип «Анализ» и раздел по большинству его показателей, приём получает врача и направление по специальности, обследование получает вид исследования. Значения, указанные пользователем при загрузке или исправленные им позже, MUST NOT заменяться. Разметка MUST NOT выдумываться: если разбор ничего не нашёл, поле остаётся пустым.

#### Scenario: Бланк биохимии без указанного типа
- **WHEN** пользователь загружает бланк лаборатории, не указав тип
- **THEN** документ получает тип «Анализ» и раздел «Биохимия», а на его странице видно, что разметка определена автоматически

#### Scenario: Пользователь исправил раздел
- **WHEN** пользователь меняет раздел документа на своё значение
- **THEN** повторный разбор и запуск приложения не меняют этот раздел

### Requirement: Документы папками
Страница «Документы» SHALL показывать документы в виде папок с числом документов в каждой: по типам и врачам (Анализы по разделам, Врачи по специальностям, Обследования по видам, Расшифровки, Заметки и прочее), по годам или по клиникам. Папки MUST строиться из разметки документов; файлы оригиналов MUST NOT перемещаться.

#### Scenario: Анализы по разделам
- **WHEN** пользователь открывает папку «Анализы → Биохимия»
- **THEN** видны только документы этого раздела, новые сверху, а фильтры по дате и типу продолжают действовать
