# Proposal

## Why

Бланки анализов одной лаборатории сделаны по одному шаблону и имеют текстовый слой. Отправлять их в модель незачем: таблицу «показатель, результат, единицы, референс» можно разобрать на компьютере бесплатно и мгновенно, и документ никуда не уходит.

## What Changes

- Локальный разбор бланков с колонками «Наименование исследования, Результат, Ед. изм., Нормальные значения, Флаг». Склеенные в текстовом слое референс и результат разделяются по правилу: у верхней границы столько же знаков после запятой, сколько у нижней, и она не меньше нижней.
- Разбор запускается сам при загрузке; для уже загруженных документов есть кнопка «Разобрать по шаблону». Неизвестный вид документа по-прежнему разбирается моделью с согласия.
- Предложения проходят ту же карточку с пометкой «Разобрано по шаблону, без модели». Флаги лаборатории (↑ ↓) попадают в пояснение.
- ФИО из бланка показывается в карточке; если оно отличается от других документов профиля, добавляется вопрос «Это документ этого профиля?».
