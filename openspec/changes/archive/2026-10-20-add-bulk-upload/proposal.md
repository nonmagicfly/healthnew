# Proposal

## Why

Пользователь хочет загружать сразу несколько документов: по одному это долго, когда накопилась папка анализов и выписок.

## What Changes

- В форме загрузки можно выбрать несколько файлов. Они загружаются по очереди, у каждого своя строка с результатом: загружен, уже был загружен или ошибка с причиной.
- Тип, дата и врач из формы применяются ко всем выбранным файлам.
- Один файл загружается как раньше: сразу открывается страница документа.

## Capabilities

### Modified Capabilities
- `source-documents`: загрузка нескольких файлов за раз.

## Impact

- Только интерфейс загрузки: API принимает файлы по одному, как и раньше.
