# Proposal

## Why

В прототипе факты извлекаются только из встроенных примеров, а чат отвечает по шаблону. Поэтому новые документы пользователя не превращаются в факты, и ответы не опираются на понимание вопроса. Пользователь выбрал следующим этапом подключение настоящей языковой модели: основной поставщик — OpenAI (ChatGPT), запасной — Anthropic (Claude).

## What Changes

- Порт `LiveModel` и адаптеры, не зависящие от поставщика: извлечение фактов и ответы чата через модель со строгой схемой ответа.
- Поставщики: OpenAI Responses API (по умолчанию) и Anthropic Messages API (запасной). Выбор и ключи задаются в `.env.local`; без ключа приложение остаётся в демонстрационном режиме и ничего никуда не отправляет.
- Явное согласие: документ отправляется только по кнопке с отметкой согласия для этого документа; чат отправляет вопрос и найденные факты только при включённом переключателе, выключенном по умолчанию.
- Правила поверх ответа модели: цитаты сверяются с распознанным текстом, документ не может подтвердить «принимаю сейчас», неверные даты становятся неизвестными, ссылки ответа чата проверяются по переданным фактам.
- Новый статус документа «Можно извлечь факты».

Вне этапа: работа через подписку ChatGPT (Codex CLI) — решение пользователя ожидается; OCR без модели; хранение ключей в интерфейсе.

## Capabilities

### New Capabilities
- `live-llm`: подключение языковой модели для извлечения фактов и ответов чата с согласием на отправку и проверкой результата.

### Modified Capabilities
Нет. Карточка предложений, правила фактов и чат работают как раньше; модель лишь даёт им новые данные.

## Impact

- Код: `src/core/rules/extraction.ts`, `src/core/rules/llm-request.ts`, `src/core/service.ts`, `src/adapters/llm/*`, `src/server/container.ts`, маршрут `documents/[docId]/extract`, интерфейс документа и чата.
- Зависимости: `openai`, `@anthropic-ai/sdk`, `zod`.
- Данные: при согласии содержимое документа или факты уходят выбранному поставщику. Ответы OpenAI запрашиваются с `store: false`.
